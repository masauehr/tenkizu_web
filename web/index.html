操作方法

地域ボタン・図のタブ上のボタンで地域（北半球／平面図／鉛直断面／エマグラム）を選び、その下のタブで図を選ぶ。エマグラムは最初は那覇
← / →予報時間を1コマ戻す / 進める（スライダーでも動かせる）
↑ / ↓同じ地域の前の図 / 次の図
Home / End最初 / 最後の予報時間
Space（再生）予報時間を自動で進める / 止める（速さは「遅い・標準・速い」）
2モデル比較（C）同じ図を ECMWF と GFS で左右に並べる。初期値が違うモデルは、予報時刻が合う別の初期値の画像を出す（見出しに初期値と予報時間が付く）。画面が狭いときは上下に並ぶ
別の図を並べる（F）右の地域に「実況エマグラム（気象庁の観測）」も選べます（地点・観測時刻を選ぶ。予報時間とは連動しません）。同じモデル・初期値・予報時間で、右に別の地域・図（例: 左に平面図、右に鉛直断面やエマグラム）を並べる。右の地域・図は選択欄で選ぶ。ローカルでは、右の地域に「自由選択（断面図・エマグラム）」も選べる（自由選択のページで作った断面図・エマグラムの直近10件から選んで出す。まだ作っていないときは案内が出る。予報時間とは連動しない。一覧は保存した画像ファイルから作るので、別のブラウザでも同じ。別のタブで作ると、最新の結果に自動で切り替わる）。公開サイトでは、作者が公開した断面図・エマグラム（直近10件）が「保存された断面図・エマグラム（公開分）」として選べる（新しく作ることはできない）。2モデル比較とは同時に使えない
下の小さな画像同じ地域の他の図（同じ予報時間）。クリックでその図へ切り替え
表示サイズ・保存画像の大きさ（既定は縦が切れないように縮める）を選べる。「保存」でその画像をダウンロード
画用紙版複数の図を並べて同時に見る（整列・初期化・配置の登録ができる）
自由選択（断面図・エマグラム）ローカルで動かしているときだけ表示。地図をクリックして、任意の断面線やエマグラムの地点を作る（公開サイトでは使えない）

図の読み方

北半球300・500等高度線＋風速のシェード。ジェット気流の蛇行を見る。500hPa の赤破線は気温、W=暖域・C=寒域・H/L=高度の極大・極小
FAX57相当500hPa気温（青線）＋700hPa湿数（緑=湿り・黄=乾燥）
FAX78相当700hPa発散・収束（シェード）＋850hPa気温（青線）・風
Qベクトル発散850hPa。赤=発散・青=収束。上昇流・下降流の目安
地上FAX海面気圧・2m気温（緑）・10m風・H/L
不安定域300hPa飽和相当温位 − 850hPa以下の最大相当温位。負（赤〜黄）が不安定
鉛直断面南北断面（130E・140E）。温位（黒）・相当温位（赤）・断面平行風（青）・発散・風矢羽。灰色は地面
エマグラム気温（赤）・露点（緑）・持ち上げ気塊・CAPE/CIN・ホドグラフ。露点は300hPa以下だけ。右上の小さな地図に、地点を赤い●で示す

予報は6時間毎で72時間先まで。時刻はすべて UTC（JST は +9時間）。予報は不確実性を含みます。防災・安全の判断には、気象庁など公的機関の公式情報を使ってください。
