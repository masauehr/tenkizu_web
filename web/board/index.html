読み込み中… 通常版 数値モデル天気図

操作方法

↑ / ↓予報時間 +1ステップ / −1ステップ（3または6時間）（Ctrl+↓: 最初、Ctrl+↑: 最後）
← / →初期時刻を 前 / 次（Ctrl+←→: 予報有効時刻を固定して初期値を変える）
マウスホイール図の上で拡大縮小（0.25〜2倍）
タイトル帯ドラッグ図を移動（クリックで最前面）
右下の▨ドラッグ図の大きさを変更
モデル違い選択中の図を、他のモデルでも同じ範囲で並べて整列（ECMWFとGFSの比較）。モデルで最新の初期値が違う場合は、予報有効時刻が一致する別の初期値の画像を出す（見出しに [初期値 +予報時間] が付く）。時刻が合わない時は「画像なし」
登録今の配置に名前を付けて保存。「登録した配置」から呼び出し
B選択中（最後に触った）の図を最背面へ
P / S再生 / 停止
T / I整列 / 配置の初期化
D / H上部メニューの表示切替 / この説明

範囲によって予報時間の刻みが違う（0.5°は6時間毎、0.125°は3時間毎）ため、刻みの粗い図は直前の予報時間の画像を表示し、タイトルに(FTxh)と出ます。配置は自動保存されます。

ECMWF だけ 18Z も載せます（06Z は取りません）。GFS は 00/12Z のみ（公開容量の都合）。公開サイトは各モデル約2日分です。時刻はすべて UTC（JST は +9時間）。

自動更新は、揃ってから次の定期起動で作図が始まり、ローカルの GSM は公開されません。
