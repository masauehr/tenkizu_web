読み込み中… 通常版 数値モデル天気図

操作方法

↑ / ↓予報時間 +1ステップ / −1ステップ（6時間）（Ctrl+↓: 最初、Ctrl+↑: 最後）
← / →初期時刻を 前 / 次（Ctrl+←→: 予報有効時刻を固定して初期値を変える）
マウスホイール図の上で拡大縮小（0.25〜2倍）
タイトル帯ドラッグ図を移動（クリックで最前面）
右下の▨ドラッグ図の大きさを変更
モデル違い選択中の図を、他のモデルでも並べて整列（ECMWFとGFSの比較）。モデルで最新の初期値が違う場合は、予報有効時刻が一致する別の初期値の画像を出す（見出しに [初期値 +予報時間] が付く）。時刻が合わない時は「画像なし」
登録今の配置に名前を付けて保存。「登録した配置」から呼び出し
B選択中（最後に触った）の図を最背面へ
P / S再生 / 停止
T / I整列 / 配置の初期化
D / H上部メニューの表示切替 / この説明

予報時間は6時間毎で72時間先までです。モデルによって初期値が違う場合や、その予報時間の画像が無い図は、直前の予報時間の画像を表示し、タイトルに(FTxh)と出ます。配置は自動保存されます（「初期化」で初期状態に戻せます）。

更新（12Z初期値の時間帯に自動更新）

GFS12Z 初期値は 16:15〜18:00 UTC ごろに揃う
ECMWF12Z 初期値は 19:40〜23:25 UTC ごろに揃う

公開サイトは UTC 17〜23時の :30（1日7回）に自動で更新され、各モデル約2日分を載せます。00Z・18Z は定期更新に入れていないので、載るのは手動で更新したときだけです。時刻はすべて UTC（JST は +9時間）。ローカルの GSM は公開されません。
